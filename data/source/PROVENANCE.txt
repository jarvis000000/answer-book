更新方式
--------
上游每日自动重建在线阅读页，正文会持续修订。要同步最新版本：

  git clone --depth 1 https://github.com/eternity4719/HowToLiveBetter.git /tmp/up
  cp /tmp/up/book/*.md data/source/
  npm run build && npm test && npm run eval

注意：条目数、A/B/C 分级一旦变化，test/parse.test.mjs 里的断言会失败——
那些数字是刻意钉住的，用来提醒「正文变了」，而不是让它们悄悄漂移。
届时需要人工核对是上游改对了还是改错了，再更新断言。
